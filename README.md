# Number Guessing Game

A simple Python project: the computer picks a random number between 1 and 99, and you try to guess it.
After each guess, the computer tells you whether to guess a bigger or a smaller number.

## Features
- Random number generation
- Input from the user
- Hints after every guess
- Counts your guesses and asks if you want to play again

## Technologies
- Python 3

## How to run
1. Install Python 3
2. Save the code as `guess.py`
3. Run `python guess.py`
